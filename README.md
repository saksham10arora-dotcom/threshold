# Threshold

Four doors in an atrium, each opening onto a different world that occupies the same space: a snow forest, a deep sea with whales, a red desert of monoliths and a neon city. Walk through them. The doors are real portals drawn with the stencil buffer, not pictures.

Live: https://saksham.digital/threshold/

WASD to walk, Shift to run, drag to look. On a phone, drag the left side to walk and the right side to look. One HTML file, three.js r128.
